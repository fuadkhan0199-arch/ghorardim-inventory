Quick start

  1. Add products with exact SKU codes used inside your QR labels.
  2. Open Scan sale and allow camera access, or use a USB/Bluetooth scanner.
  3. Each valid scan deducts one unit immediately. Avoid scanning the same item twice.

A stock deduction is recorded in the cloud and visible on other signed-in devices after refresh.

Import product CSV

Use a CSV with headers: sku,name,price,cost,stock,low_stock. SKU values must match your QR labels. Example:

sku,name,price,cost,stock,low_stock
GD-001,Metal Fidget Slider,749,250,12,3
GD-002,T13 Dummy Figure,349,96,20,5

Import updates product details for existing SKUs and sets opening stock only for new products. Do not import the same file repeatedly to add stock.
